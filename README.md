# Human-Computer Interaction — TU Graz

Course website for **INH.02021UF Human-Computer Interaction**, offered in summer semester 2027 at TU Graz.

The site is built with [Jekyll](https://jekyllrb.com/). To preview it locally:

```sh
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000/hci-2027/`.
